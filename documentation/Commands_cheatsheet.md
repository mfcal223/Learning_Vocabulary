Para iniciar el programa ubicado en 
```
~/proyectos/Learning_german
```
Entra en la aplicación:
```
cd deutsch-cards
```
Después ejecuta:
```
npm run dev
```
Deberías obtener algo parecido a:
```
VITE v...
Local:   http://localhost:5173/
```

Entonces puedes hacer **Ctrl + click** sobre la dirección que aparezca, o abrirla en el navegador.
